# Getting started

## Create a sequence

1. As GM, open the clapperboard **Stagecraft** tool in the scene controls and choose **Open editor**.
2. Choose **New sequence**. A new sequence starts with a **Cinematic bars** clip. Use **Rename sequence** to give it a name.
3. Add a **Title** from the Library. Select it, then use **Clip → Content** to enter the text. Use **Clip → Animation** to choose its In and Out animations.
4. Position the title in the preview. Set its start and length in **Clip → Timing**, or move and trim its clip on the timeline.
5. Choose **Preview** to check the sequence, then save.

## Play for your group

1. Save the sequence. **Prepare playback** uses a saved sequence and is unavailable while edits are unsaved.
2. Choose **Prepare playback**. In the **Audience** dialog, select **All players** or **Selected players**. Turn on **Also show to GM** if you want the GM client to display it too, then choose **Prepare**.
3. Open **Playback control** from the editor or the Stagecraft scene-control tool. When **Start playback** is enabled, choose it.

**Preview** stays inside the editor. **Play here** runs the sequence on your own client.

For recipes using Breaks and interactive buttons, see [Tutorials](tutorials.md). For playback settings and troubleshooting, see the [Reference](reference.md).
